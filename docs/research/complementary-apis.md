# Complementary APIs for Kuroyume

Verified against provider documentation on 19 September 2026. This is a provider-selection recommendation, not an integration or a live reliability benchmark. No MCP discovery or credentials were used. Baseline supplied for this research: RapidAPI MAL already covers search, top lists, details, genres, recommendations, reviews, and seasons; its exact subscription limits and manga coverage still need confirmation.

## Recommended minimum

Keep **RapidAPI MAL as the initial anime catalogue**. Add **Jikan v4 only for missing manga/manhwa discovery and richer detail sections**. Use supplied, verified YouTube trailer IDs in the official embedded player; a YouTube Data API subscription is unnecessary just to embed a known video. Add **TMDB later** when regional availability or broader artwork is a committed feature. This keeps provider matching, attribution, and failure handling manageable. [YouTube embedding](https://developers.google.com/youtube/iframe_api_reference)

Do not choose AniList as Kuroyume's primary database without a provider agreement covering this product. Its current terms prohibit competing, non-complementary anime/manga list or tracker services, explicitly covering **media data as well as user data**. A free application or an OAuth connection does not independently remove that restriction. [AniList terms](https://docs.anilist.co/guide/terms-of-use)

## Terms and operational consequences

- **AniList:** no data hoarding/mass collection or use as backup storage. Commercial use below $150 monthly revenue is free under the stated commercial section; above $150 requires a commercial license. That section does not override the competing-service restriction. The exactly-$150 boundary is not clearly expressed. [Terms](https://docs.anilist.co/guide/terms-of-use)
- **Jikan:** an unofficial scraper sharing MAL as its upstream, not a separate licensed catalogue. Its repository directs consumers to respect MAL terms; its MIT software license should not be treated as ownership of MAL text/images. The dedicated Jikan terms URL was unavailable to the research browser, so commercial/data-reuse clearance remains unverified. Published cache duration is 24 hours: do not promise real-time updates. [Repository disclaimer](https://github.com/jikan-me/jikan-rest#disclaimer), [schema/cache policy](https://raw.githubusercontent.com/jikan-me/jikan-rest/master/storage/api-docs/api-docs.json)
- **Kitsu:** documentation is being migrated and some authentication guidance is legacy. Commercial catalogue/image reuse and a firm service quota were not verified; open-source/documentation licensing alone does not settle those questions. Confirm current supported auth before implementing account sync. [Official documentation repository](https://github.com/hummingbird-me/api-docs), [API docs](https://hummingbird-me.github.io/api-docs/)
- **TMDB:** noncommercial use is free with required logo and endorsement disclaimer in About/Credits; revenue-oriented projects need commercial licensing. Watch-provider data additionally requires **JustWatch attribution**. Availability is per country and supplies a TMDB destination, not complete direct playback links. It does not authorize streaming the content. [FAQ/licensing](https://developer.themoviedb.org/docs/faq), [watch-provider requirements](https://developer.themoviedb.org/reference/tv-series-watch-providers)
- **YouTube:** retain official player behavior/branding; do not download or rehost videos. Limited public API metadata must be refreshed or deleted within 30 days under the non-authorized-data rule. Prefer click-to-load trailers without autoplay; embedding also shares visitor data with YouTube. [Developer policies](https://developers.google.com/youtube/terms/developer-policies)

## Integration decisions

Use an internal media ID with namespaced provider IDs; MAL anime and manga IDs must include media type. Jikan can match existing MAL IDs directly. Kitsu has mappings, but missing mappings must remain unresolved. Treat TMDB series/seasons and MAL season-specific anime entries as potentially different units; never silently join on title alone. Keep original provider scores labeled rather than blending unrelated rating populations.

Fetch enrichment after core content, through server-side adapters with timeouts, request deduplication, bounded retries/backoff and provider-wide rate budgeting. Keep provider credentials server-only. Cache per provider rules and show useful partial pages when optional services fail. Store source and fetch time alongside fields so attribution, refresh and provider removal are feasible.

Before widening the provider set, evaluate a small representative sample of Japanese manga, Korean manhwa, adaptations, sequels and obscure titles. Measure missing records, image coverage and matching mistakes. Catalogue support does not imply licensed chapter pages, legal reading destinations or real-time Korean release schedules; none of these five providers establishes those capabilities by itself.
